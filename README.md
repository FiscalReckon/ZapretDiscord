>

## ⚙️Использование

1. Настройте Безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы - [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант
    * На роутерах Keenetic активируйте параметр "Транзит запросов". При отключенной опции Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/FiscalReckon/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и включите пункт "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется

4. Распакуйте файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для установки запуска вместе с системой выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегий

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из списка служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - переключить режим обхода для сервисов из `ipset-all.txt`.  
  Настройка полезна при проверке ресурса, который без zapret работает, а с ним - нет  
  Возможные значения:
    - `none` - ни один IP не участвует в проверке
    - `loaded` - IP проверяется по списку
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** - заменить используемый фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - получить свежий `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - проверить распространённые причины неисправности zapret.  
  В финале можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы
  - **`Run Tests`** - открыть проверку стратегий:
    - `Standard tests` - протестировать сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/FiscalReckon/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте текстовым редактором от имени администратора файл `hosts` в появившемся каталоге
  - Вставьте скопированное в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и снова проверьте подключение. При проблемах убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/FiscalReckon/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который некоторое время работал, может перестать работать после его обнаружения.
> Здесь собрано много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них, изменив её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что в `service.bat` -> `Run Diagnostics` нет ошибок

- Проверьте, что адрес нужного ресурса включён в списки доменов или IP

- Попробуйте другие стратегии, например **`ALT`** или **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Ознакомьтесь с [#765](https://github.com/FiscalReckon/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и настройки
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y
- Удалите старый каталог с запретом
- Скачайте свежую версию [со страницы релизов](https://github.com/FiscalReckon/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива через ПКМ. Если внизу справа есть пункт разблокировки, включите его, нажмите "Применить" и "ОК"
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте доступность ресурсов. Если текущий вариант не подходит, закройте программу через значок замка на панели задач и попробуйте следующий
- После выбора рабочей стратегии установите её в автозапуск через `service.bat` -> `Install Service`

### Не работает игра/приложение с включённым запретом

- Проверьте в service.bat, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция находится здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. В командной строке Windows, открытой через Win+R и `cmd`, найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Переберите остальные стратегии, особенно если ранее всё работало
- Дополнительная информация есть в [#251](https://github.com/FiscalReckon/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord
- Проверьте, запустилось ли приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ею
- Если Discord не открывается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/FiscalReckon/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/FiscalReckon/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно стоит сделать следующее:
- обновить ipset через `service.bat` и включить `Game Filter`
- если результата нет, дополнительно включить `ipset any`

Учтите, что `ipset any` может нарушить доступ к множеству сайтов. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/FiscalReckon/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/FiscalReckon/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Добавлять дополнительные адреса для обхода можно в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети для исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
